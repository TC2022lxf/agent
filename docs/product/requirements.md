# 产品需求与范围

状态：根据代码反向整理的候选需求，待项目所有者确认；核验日期：2026-11-19。
来源：[Agent 注册](../../backend/app/agents/builtin.py)、[应用入口](../../frontend/src/App.tsx)、[协作服务](../../backend/app/services/collab.py)、[账户/计费测试](../../backend/tests/test_auth_billing.py)。

## 产品问题与目标用户（待确认）

当前实现面向需要持续迭代电商内容的人：通过自然语言表达目标，在可见工作台检查文案、图片、页面布局及历史版本。角色包括内容操作者、管理员；仓库使用者还包括产品负责人、开发者和编程 Agent。

这是从实现推导的产品描述，不是已获用户访谈支持的商业定位。目标市场、收费策略、规模、质量阈值、发布目标和优先级均待负责人确认。

## 已确认的 workspace 原则

2026-11-19，项目所有者明确：agent workspace 也是 human workspace；文档用于理解项目、指引 AI 工作并验证 AI 工作。人保留需求确认、产品验收和发布决定权。删除旧误导文档，不删除业务/用户数据，不在日常工作区另存旧资料副本。

## 候选需求清单

下列各项的**需求确认状态均为待负责人确认**；“已实现”只描述代码行为，验收参见同编号域的 AC。

| 编号 | 用户目标与候选需求 | 范围/关键边界 | 当前实现 |
| --- | --- | --- | --- |
| REQ-GEN-001 | 在同一任务对话内持续创建、读取和修改多类产物 | 文件/图片/PDP/Canvas；工具由 Agent 注册权限约束 | 已实现，效果待真实模型验证 |
| REQ-PDP-001 | 分槽位生成与修改 PDP，保留其他槽位和历史 | title/bullets/description/search_terms/图片；不是自动发布 Amazon | 已实现 |
| REQ-IMG-001 | 生成图像及基于当前版本的区域编辑 | 拒绝不支持的操作，不伪造成功；真实图像效果另验 | 已实现 |
| REQ-CAN-001 | 创建并局部修改布局，支持人工拖动和外部 MCP 操作 | 结构化 screen/module/theme，图片引用版本；不是自由白板 | 已实现 |
| REQ-RULE-001 | 将长期约束作为待确认草稿，确认后生效 | 偏好 proposal 与任务 constraint 不混同 | 已实现 |
| REQ-VER-001 | 版本可追踪，拒绝版本不替换当前版本，恢复不抹掉历史 | 验证、当前指针和恢复产生的新版本分开 | 已实现 |
| REQ-AUTH-001 | 用户隔离、邀请注册/会话与管理员权限 | 开发身份与生产 session 区分；不是已完成安全审计 | 已实现 |
| REQ-COST-001 | 运行前冻结预算，结束结算，异常退款可追溯 | 积分账本、人工充值确认；未接真实在线支付 | 已实现 |
| REQ-RUN-001 | 重复请求不重复执行，失败/取消可见且可恢复 | 幂等键、任务冲突、重排队/恢复有边界，不保证无限重试 | 已实现 |
| REQ-UX-001 | 看见回答进度、工具结果、最终状态和需要用户回答的问题 | SSE 增量不是最终权威记录；需浏览器/人工验证体验 | 已实现 |

## 非目标与未确认事项

不把占位自动化、真实支付集成、自动发布平台、生产级多实例伸缩、全面安全合规或已量化模型质量当作本期承诺。上述能力若需要，先另提目标、验收标准和预算。

需求负责人需确认：用户优先级、各场景是否进入下一版本、可接受耗时与成本、图像/文案质量口径、发布环境。未获得答案前按[探索差距](../exploration/current-state.md)登记，不编造阈值。

## 用需求工作

给 AI 任务时引用本页 REQ 和对应 [AC](acceptance.md)，注明变更是否扩展范围。完成后沿[追踪矩阵](../quality/traceability.md)查实现、用例和报告；不以“现有测试覆盖”替代产品确认。
