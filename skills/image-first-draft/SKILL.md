# 图像第一版

> 图像槽位还是空的，用户要“来一张”时用。已经有版本后改用 `image-local-edit`。

## 适用

图像 Artifact 还没有任何 Version。主图、场景图、特写都按这条起手。

## 推荐步骤

1. 先确认这张图的用途：主图、场景、特写，还是副图。用途决定背景和是否允许文字。
2. 一句话说清想呈现的主体和场景，再调一次 `generate_product_image`。
3. 主图不要加促销文字。副图可以有文字，但文字内容要用户确认。
4. 出图后停下，让用户看。不要一次生成一堆备选。

## 可用工具

- generate_product_image

## 约束

主图的白底、主体占比等规则来自平台约束包。`product_scale`、放大和抠图在实验通过前不承诺可控。

## 可偏离

用户已经给了完整描述时，不要追问，直接生成。

## 评价

主图规则由 Runtime 自动检查。被拒绝的版本不会成为当前版本。

## 输出

图像槽位的第一版 Version。
