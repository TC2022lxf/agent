# PDP 优化已有 Listing

> 用户说“优化我的 Listing”“改得更能搜到”时用。不是从零写一版。

## 适用

任务里已经有 `origin = imported` 的第一版。从零写一套用 `listing-first-draft`。

## 推荐步骤

下面是建议顺序。可以跳过、回退或换 Skill。实际路径记在 Run 上。

1. 先看当前版本和它记录的规则问题，不要凭感觉重写全部。
2. 只改有问题的槽位，一次一个 `edit_listing`，`base_version_id` 是导入版。
3. 保持商品事实不变。导入稿里没有的参数不要补。
4. 改完一处就停，让用户看差异，不要一口气把所有槽位都换掉。

## 可用工具

- edit_listing

## 约束

标题长度、五点长度、后台关键词上限都由平台约束包决定，本文不写数字。

## 可偏离

用户已经指出具体槽位时，直接改那一个，不先做整体检查。

## 评价

硬约束失败的新版本不会被设为当前版本。不要为了让长度通过而删掉商品事实。

## 输出

在已有槽位上产生新 Version。
